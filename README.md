# Благодійний Забіг - Система обліку кіл

Веб-додаток для обліку кіл учасників благодійного забігу, розділених за факультетами.

## Функціонал

- Відстеження кіл для кожного факультету (студенти та викладачі)
- Додавання благодійних донатів для факультетів
- Автоматичне оновлення рейтингу факультетів
- Стрічка останніх активностей

## Встановлення

1. Переконайтеся, що у вас встановлено Python 3.7 або новішої версії

2. Клонуйте репозиторій або скопіюйте файли у вашу директорію

3. Встановіть залежності:
```
pip install -r requirements.txt
```

## Запуск додатку

1. У терміналі перейдіть до директорії проекту:
```
cd /Users/oleksii/Documents/PROJECTS/counter_for_run
```

2. Запустіть сервер Flask:
```
python app.py
```

3. Відкрийте веб-браузер і перейдіть за адресою:
```
http://127.0.0.1:5000/
```

## Система нарахування балів

- 1 коло студента = 1 бал
- 1 коло викладача/адміністратора = 3 бали
- Кожні 100 грн донатів = 1 бал

## Технічні деталі

- Backend: Python з використанням Flask
- База даних: SQLite
- Frontend: HTML, CSS (Bootstrap), JavaScript
